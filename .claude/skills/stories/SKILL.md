# Stories HORIZON

## Secuencia tipo (5–7 frames)
1. **Gancho:** situación real del día (cliente, proyecto, error, aprendizaje).
2. **Contexto:** el problema detrás.
3. **Interacción:** encuesta / slider / caja de preguntas (genera señal para el algoritmo y datos para OPS).
4. **Valor:** el insight o cómo lo resolvimos.
5. **Prueba:** captura, resultado o testimonio.
6. **CTA:** responder con palabra clave / link a `/recursos` o `/agendar` (solo si el público ya está en Modo 3).

## Visual
Mismo sistema "Burbujas" del carrusel (`.claude/skills/carrusel/SKILL.md` → Dirección visual), formato `.pz.story` 1080×1920. Los frames de gancho y prueba usan burbujas Sin/Con; los de interacción dejan libre el tercio inferior para el sticker.

## Formato de entrega
Tabla por frame: texto en pantalla (máx. 15 palabras) · sticker · visual · nota de grabación.
Guardar en `CONTENIDO/stories/AAAA-MM-DD-<slug>.md`.
