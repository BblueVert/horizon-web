# Estructura — Acta de entrega y recepción conforme

- Título: `Acta de Entrega`
- Subtítulo: `{{PLAN_NOMBRE}} — {{CLIENTE_NOMBRE_FANTASIA}}`
- Código: `HZ-{{AAAA}}-{{slug}}-AE`

## Secciones
1. **Datos** (tabla): cliente, plan, contrato asociado (código CON), fecha de entrega.
2. **Entregables** (tabla): entregable del Anexo A · estado (Entregado / Pendiente) · URL o ubicación.
3. **Accesos transferidos** (tabla): servicio · cuenta / usuario · a nombre de. Nunca escribir contraseñas en el acta: se entregan por un canal aparte.
4. **Capacitación realizada:** fecha y temas (cómo usar el CRM, el panel, cómo pedir cambios).
5. **Soporte:** el mes incluido corre desde {{FECHA_ENTREGA}} hasta {{FECHA_FIN_SOPORTE}}. Desde ahí, soporte opcional de {{MONTO_SOPORTE}} mensuales, mes a mes.
6. **Garantía:** 30 días para reportar errores de funcionamiento.
7. **Estado de pagos:** total, pagado y saldo pendiente con fecha de pago.
8. **Observaciones** (pendientes acordados, si hay).
9. **Recepción conforme:** "El Cliente declara recibir a conformidad los entregables indicados, salvo las observaciones anotadas." + firmas.
